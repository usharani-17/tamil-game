# Tamil Game – Thirukkural Puzzle

## Overview

Tamil Game is an educational web application built using React and Vite. The game presents a Thirukkural in a jumbled format, and the user must arrange the words in the correct order to form the complete Kural.

## Features

* Interactive Thirukkural word puzzle
* Arrange the seven words of a Thirukkural in the correct order
* Instant answer validation
* Correct and incorrect result indication
* Built-in timer to track completion time
* Simple and user-friendly interface

## Technologies Used

* React.js
* Vite
* JavaScript
* HTML
* CSS

## How the Game Works

1. A Thirukkural is displayed in a shuffled order.
2. The user selects and arranges the words in the correct sequence.
3. After arranging all seven words, the user submits the answer.
4. The system checks whether the arrangement is correct.
5. A correct answer displays a success message, while an incorrect answer prompts the user to try again.
6. The timer records the time taken to complete the puzzle.
